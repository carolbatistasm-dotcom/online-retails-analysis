# Online Retail Analysis

Exploratory data analysis of the UCI Online Retail dataset using Python and Pandas.

## Overview

This repository contains an exploratory data analysis workflow developed in Python using the Online Retail dataset from the UCI Machine Learning Repository.

The analysis focuses on data cleaning, transaction-level exploration, cancellation identification and revenue impact.

## What I Practiced

* Data import with Pandas
* Data inspection and exploratory analysis
* Missing value identification
* Duplicate detection and removal
* Feature creation
* Boolean filtering
* String manipulation
* Cancellation identification
* Revenue calculations
* Basic business-oriented data interpretation


## Technologies

Python · Pandas · Visual Studio Code · Jupyter · Git · GitHub

## Dataset

The dataset used in this project is the **Online Retail Dataset**, available through the UCI Machine Learning Repository.

It contains transactional data from a UK-based online retailer, including invoice information, products, quantities, dates, prices, customers and countries.

The original dataset is not included in this repository.

## Context

This project was developed as part of my practical studies in Python and Data Analysis, with the goal of improving my skills in exploratory data analysis, data cleaning and interpretation of real-world transactional data.
